# Sanad-GRC-Tool

A GRC (Governance, Risk & Compliance) dashboard prototype built with Python, Streamlit and pandas, created as part of my Information Security diploma.

## Features
- Risk register with filtering and KPIs calculated from the data
- Controls and evidence tracking (control, evidence owner, last test date, test result)
- Policy and compliance tracking

Note: the data shown is sample data for demonstration purposes.

## Run
pip install -r requirements.txt

streamlit run sanad_grc.py
